# Plugmix for FontLab

Use App-based menu scripts for reporter overlays, or the retained compatibility package for its separate reporter, Filter, Palette, Tool and General runtime. The recovered source preserves both histories; they are not consolidated.

The [App menu-script catalogue](app-menu-scripts.md) accounts for all 39 reporter launchers and the menu installer. The [compatibility package](compatibility-package.md) retains all 19 reporters and the other plugin kinds. Read [installation](installation.md) before choosing a runtime, and [development and limits](development-and-limits.md) before relying on native behavior. [LICENSE and NOTICE](licence.md) retain the Apache and MIT terms.

Choose one runtime per FontLab session. Both can create Plugmix menus and use `fontlab-plugmix.json`; their startup installers and saved preferences are not interchangeable. Native cross-runtime migration and recovery remain unqualified.

This complete local source/generated website does not publish private Pages. Its configured URL is the future repository identity only. Builds import neither plugin runtime and do not start or drive FontLab.
