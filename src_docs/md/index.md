# Plugmix for FontLab

Use the Extensions pack with App's `fontlabapp.plugins` core: 39 reporters, one Filter, one Palette, one Tool and one General plugin. The retained `fontlab_plugmix` compatibility package is a separate runtime.

The [App Extensions catalogue](app-menu-scripts.md) lists all 39 reporter bundles and their limits, the four other bundles and the optional Show Reporters action. App discovers the Extensions at startup; enable reporters in the Reporters palette or View > Reporters. The [compatibility package](compatibility-package.md) retains all 19 reporters and the other plugin kinds. Read [installation](installation.md) before choosing a runtime, and [development and limits](development-and-limits.md) before relying on native behavior. [LICENSE and NOTICE](licence.md) retain the Apache and MIT terms.

Choose one runtime per FontLab session. Both use `fontlab-plugmix.json`; their startup installers and saved preferences are not interchangeable. Native cross-runtime migration and recovery remain unqualified.

This complete local source/generated website does not publish private Pages. Its configured URL is the future repository identity only. Builds import neither plugin runtime and do not start or drive FontLab.
