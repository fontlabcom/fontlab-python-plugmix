    App Extensions catalogue

    All 39 reporter bundles below live in Extensions/reporters/. Each has its own plugin.json and Python source; no package install or individual launcher is needed for a bundle. Bundles and the action require fontlab-fly>=1.3.0 and its providers; their API imports use fly.ap, preserving canonical App identity. App's fontlabapp.plugins core owns discovery, painter registration, preferences, rollback and teardown. fontlabapp.plugmix remains a deprecated import shim, separate from the retained fontlab_plugmix runtime.

    App's startup hook discovers the Extensions folder. Enable or disable reporters in the Reporters palette or View > Reporters; enabling persists the stable ID. Reporters do not edit font geometry. Scripts/Plugmix/Show Reporters.py is the remaining optional action script: it opens the palette. Do not combine the two runtimes' startup paths. See installation for setup.

    Other Extensions

    The same pack supplies Extensions/filters/DeleteSmallPaths.fontlabfilter, Extensions/general/ZoomToSelection.fontlabgeneral, Extensions/palettes/StepAndRepeat.fontlabpalette and Extensions/tools/SmartSelect.fontlabtool, each with a plugin.json manifest. These provide Delete Small Paths, Zoom to Selection, Step and Repeat and Smart Select respectively. App owns their host operations; filters and palettes use its guarded writer APIs. Native Undo/Redo and saved/reopened behavior remain unverified for this installed tuple.

    New filters and tools

    • Round Outline to Grid snaps own outline nodes to a grid.
    • Move Outlines translates outlines without changing advance widths.
    • Scale Outlines scales outlines about a chosen pivot.
    • Slant Outlines applies geometric shear.
    • Measurement Ruler measures a dragged span.
    • Node Probe inspects nearby outline nodes.
    • Contour Picker selects a contour by a nearby node.

    The four coordinate filters preserve components, anchors, advance widths and native curve types. Tools do not change geometry. Their pages describe scope, parameters and interaction limits; native verification remains open.

    Painting and acceptance limits

    Center Lines, Vertical Metrics, Crosshair, Tops and Bottoms, RSB Line, Unitizer, Node Count, Smart Plumblines, Show Stems, Speed Punk, Show Rotated, Show Label Color, Show Glyphs In Label Color, Show Character, Rekha Viewer, Show Background, Color Toner, Show Global Glyph, Show Siblings, Show Kerning Group Reference and Show Interpolation draw under the native glyph layer when native canvas painters are available; the rest draw over it, and on older builds all draw over the canvas. The original seven reporters, native canvas drawing and all 18 pre-revision reporters were checked in FontLab 9; Glyph Focus and the revised slant and unit grid have offline coverage only. Node Count, All Angles, Smart Plumblines, Show Stems, Speed Punk, Show Rotated, Blindfold, Show Label Color, Show Glyphs In Label Color, Show Character, Rekha Viewer, Show Export Status, Show Background, Color Toner, Show Global Glyph, Show Siblings, Show Kerning Group Reference, Kern Indicator, Show Interpolation and Stem Thickness have offline test coverage only.

    App reporter contract

    Write a reporter by subclassing fly.ap.plugins.Reporter with a unique name, a title and a pure compute(snapshot) that returns Mark objects (ring, line, polyline, polygon, text) in glyph units; pixel sizes are view pixels. Set layer = "background" to paint under the glyph layer. An error raised by compute or requested_glyphs goes to the error sink once per reporter and message until Plugmix is uninstalled. Every snapshot also carries identity (name, Unicodes, raw mark, mark RGB, export flag) and view.px_per_unit; either is None when it cannot be read, and the read error goes to the plugin error sink once. Mark RGB uses HSL lightness 0.65, so it differs slightly from FontLab's flag swatches (inferred, unverified natively). Offline coverage only. Opt-in class flags add costlier data: needs_components gives components (base name, transform and decomposed base contours, nested up to 8 levels), needs_background gives background (the mask's contours, () when empty, None when there is none), and needs_masters gives masters (each master's contours, anchors, advance and a compatible flag that compares contour count, node count per contour and on/off-curve pattern with the shown layer, ignoring components and open/closed state). Components and masters are cached per glyph revision and shared by all reporters; components also re-check their base glyphs. Master outlines may lag until the foreground glyph's lastModified moves, which is unverified natively. The background is read on every paint. An empty component layer means the master that owns the shown layer. Metrics also come from that master. Zones and the italic angle need a master switch to read, so when the shown layer belongs to another master the zones are empty and the italic slant is the current master's. Skipped components and failed reads go to the error sink once. Offline coverage only. needs_kerning gives kerning_groups (the classes used when the glyph is a pair's first member, left, and second member, right, with their members), read on every paint because a class edit may not move the glyph's timestamp. Override requested_glyphs(identity, kerning_groups=None) to name up to 32 other glyphs; others maps each one that exists to its own unselected contours (components skipped), cached per requested glyph's revision. Both use the master that owns the shown layer. needs_neighbours gives view.neighbours: the previous and next glyph on the same line as (name, kerning), kerning in font units as displayed (0 when kerning processing is off). Which glyph stores a pair's kerning is inferred, unverified natively. Neighbours need the native canvas painter backend; with EditorPainters, or when the view scale is unusable, they are None. Offline coverage only. needs_mouse gives view.mouse, the cursor in the glyph's own units (canvas.mousePosition() mapped back through the glyph and text-block transforms), or None when the map is not invertible. While any enabled reporter asks for it, one event filter watches the active glyph window and flushes (updateScreenRect plus updateViewport) at most once per 16 ms after mouse moves, ending with a flush after the last move. The filter goes when the last such reporter is disabled, when the active canvas changes or closes, and on uninstall(). Only the watched canvas gets a mouse; with EditorPainters it is None. Whether moves reach the filter under every tool is unverified natively. Offline coverage only. Bundles declare id, name, kind, version, entry and min_app_version in plugin.json. The ID, display name and kind must match the entry class; IDs are unique across kinds and the entry module must be inside the bundle. Invalid manifests and imports are logged and skipped. Discovery is sorted and retains class identity on repeated scans; restart FontLab to load changed source. Third-party packages can still use the retained fontlabapp.plugmix entry-point group.

Native palette/menu synchronization, toolbar placement, startup, teardown, drawing and writer history still require qualification on the exact installed App/Plugmix tuple.
