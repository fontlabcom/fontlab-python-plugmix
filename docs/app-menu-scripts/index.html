    App menu-script catalogue

    All 39 launchers below live in Scripts/Reports/ and call App's fontlabapp.plugmix, not fontlab_plugmix. They enable the named reporter in every Glyph window; the matching View > Plugmix: Show action disables it. They do not edit font geometry. App owns discovery, painter registration, preference saves, rollback and teardown.

    Scripts/Plugmix/Install Plugmix Menu.py is the fortieth recovered file: it installs the App menu and restores saved plugin choices without enabling an additional reporter. The two runtimes' startup paths must not be combined.

    Painting and acceptance limits

    Center Lines, Vertical Metrics, Crosshair, Tops and Bottoms, RSB Line, Unitizer, Node Count, Smart Plumblines, Show Stems, Speed Punk, Show Rotated, Show Label Color, Show Glyphs In Label Color, Show Character, Rekha Viewer, Show Background, Color Toner, Show Global Glyph, Show Siblings, Show Kerning Group Reference and Show Interpolation draw under the native glyph layer when native canvas painters are available; the rest draw over it, and on older builds all draw over the canvas. The original seven reporters, native canvas drawing and all 18 pre-revision reporters were checked in FontLab 9; Glyph Focus and the revised slant and unit grid have offline coverage only. Node Count, All Angles, Smart Plumblines, Show Stems, Speed Punk, Show Rotated, Blindfold, Show Label Color, Show Glyphs In Label Color, Show Character, Rekha Viewer, Show Export Status, Show Background, Color Toner, Show Global Glyph, Show Siblings, Show Kerning Group Reference, Kern Indicator, Show Interpolation and Stem Thickness have offline test coverage only.

    App reporter contract

    Write a reporter by subclassing fontlabapp.plugmix.Reporter with a unique name, a title and a pure compute(snapshot) that returns Mark objects (ring, line, polyline, polygon, text) in glyph units; pixel sizes are view pixels. Set layer = "background" to paint under the glyph layer. An error raised by compute or requested_glyphs goes to the error sink once per reporter and message until Plugmix is uninstalled. Every snapshot also carries identity (name, Unicodes, raw mark, mark RGB, export flag) and view.px_per_unit; either is None when it cannot be read, and the read error goes to the plugin error sink once. Mark RGB uses HSL lightness 0.65, so it differs slightly from FontLab's flag swatches (inferred, unverified natively). Offline coverage only. Opt-in class flags add costlier data: needs_components gives components (base name, transform and decomposed base contours, nested up to 8 levels), needs_background gives background (the mask's contours, () when empty, None when there is none), and needs_masters gives masters (each master's contours, anchors, advance and a compatible flag that compares contour count, node count per contour and on/off-curve pattern with the shown layer, ignoring components and open/closed state). Components and masters are cached per glyph revision and shared by all reporters; components also re-check their base glyphs. Master outlines may lag until the foreground glyph's lastModified moves, which is unverified natively. The background is read on every paint. An empty component layer means the master that owns the shown layer. Metrics also come from that master. Zones and the italic angle need a master switch to read, so when the shown layer belongs to another master the zones are empty and the italic slant is the current master's. Skipped components and failed reads go to the error sink once. Offline coverage only. needs_kerning gives kerning_groups (the classes used when the glyph is a pair's first member, left, and second member, right, with their members), read on every paint because a class edit may not move the glyph's timestamp. Override requested_glyphs(identity, kerning_groups=None) to name up to 32 other glyphs; others maps each one that exists to its own unselected contours (components skipped), cached per requested glyph's revision. Both use the master that owns the shown layer. needs_neighbours gives view.neighbours: the previous and next glyph on the same line as (name, kerning), kerning in font units as displayed (0 when kerning processing is off). Which glyph stores a pair's kerning is inferred, unverified natively. Neighbours need the native canvas painter backend; with EditorPainters, or when the view scale is unusable, they are None. Offline coverage only. needs_mouse gives view.mouse, the cursor in the glyph's own units (canvas.mousePosition() mapped back through the glyph and text-block transforms), or None when the map is not invertible. While any enabled reporter asks for it, one event filter watches the active glyph window and flushes (updateScreenRect plus updateViewport) at most once per 16 ms after mouse moves, ending with a flush after the last move. The filter goes when the last such reporter is disabled, when the active canvas changes or closes, and on uninstall(). Only the watched canvas gets a mouse; with EditorPainters it is None. Whether moves reach the filter under every tool is unverified natively. Offline coverage only. Third-party packages publish plugin classes in the fontlabapp.plugmix entry-point group.
